# Orbital Run: Station 7

A small, server-built Roblox obstacle course set aboard a space station. The course includes five checkpoints, moving platforms and hazards, a void reset, a finish trigger, a wins counter, and a live HUD.

## Project layout

- `default.project.json` — Rojo project mapping.
- `src/server/OrbitalRun.server.lua` — builds the course and owns checkpoint, hazard, respawn, and finish logic.
- `src/client/OrbitalRun.client.lua` — creates the HUD and displays server status messages.

## Open in Roblox Studio

1. Install [Rojo](https://rojo.space/) and its Roblox Studio plugin.
2. From this folder, run `rojo serve`.
3. In Studio, open a new Baseplate place and connect the Rojo plugin to the running server. The project will sync its scripts into the place.
4. Press **Play** to test. The course is generated by the server script when the server starts.

To create a place file instead, run `rojo build -o OrbitalRun.rbxlx` and open the resulting file in Studio. Publish the place from Studio using **File → Publish to Roblox**; repository publishing does not publish to the Roblox game platform.

## Controls

Use **WASD** or the arrow keys to move and **Space** to jump. Reach each cyan checkpoint pad to save your progress for the current server. Red moving hazards and falling below the course reset you to your latest checkpoint. Touch the gold finish beacon to record a win.

## Checks

The project mapping is standard Rojo JSON. The repository does not include a Roblox place binary or Roblox credentials; final playtesting and publishing the place to Roblox must be done through Studio.
